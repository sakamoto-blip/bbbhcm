# 研修スライド 制作計画（全章）

各章の投影用資料・台本・マスターデータを踏まえた、型の更新方針と章ごとの演出案、原稿の確認事項。

## 決定済みの方針

- 背景はすべて淡い色。濃い地は使わない
- 過激な表現は使わない。アニメーションは積極的に使う
- 写真が必要な箇所は「画像」枠を置き、こちらで用意する
- 文字は通常のゴシック（筆文字・落款は使わない）
- フッター中央に BALNIBARBI ロゴ（表紙から）
- 修了レポートのスライドには項目一覧を載せない（提出方法・期限・記入方法・QR・注意書きのみ）
- 第2章の3原則は「付けない・増やさない・やっつける」

## 全体の修正（反映済み）

- 表紙の「オンライン研修」「60分」を削除
- 画面の下にマウスを近づけると、スライド一覧のバーが出る（クリックで移動）
- P キーで発表者ウィンドウ（台本・時間・次のスライド・一覧・操作ボタン）
- 人は塗りの人型ピクトグラムに。大きなアイコンは種類に合わせて動き続ける
- 「まず、お答えください」と「皆さんの回答」の2枚を、質問内容とZoomのチャットでの回答方法の1枚に
- 「何を失うか」の個人の責任に、刑事・民事のラベル
- [ ] チャットの送信先「全員」だと名前が見える（匿名ではなくなる）。「ホストのみ」にするか
- [ ] 第1章の質問文は、台本の項目から作った案（投票設問ファイル未受領）
- [ ] 第3章の民事責任の文言（マスターデータに個人の民事責任の記載がない）

## 4. 進め方

1. 共通の型に1の部品を追加し、型見本を更新する
2. 第2章から順に、1章ずつ作る。各章の確認事項はその章を作る前に決める
3. 修正はスライド番号ごとにまとめて依頼してもらう
