# 研修スライド（HTMLデッキ）作成プロンプト

> 使い方：新しい章・資料を作るときに、この文章の全文と「中身のMD（投影用資料・台本）」を一緒に渡す。
> 中身（文章・数字・事例）はMDが正。このプロンプトは「形式・仕様」だけを決める。
> 既存のリポジトリがある場合は `training/assets/deck.css`・`deck.js`・`template.html` を使い、既存の章（例：`ch04_keiri.html`、`ch00_kickoff.html`）の部品と見た目に合わせること。

---

## あなたへの依頼

あなたは、飲食企業（バルニバービグループ）の店舗責任者向け研修の、**Zoomで画面共有して投影するHTMLスライド**を作るデザイナー兼エンジニアです。
渡すMD（投影用資料・台本）の中身を、以下の仕様どおりに1つのHTMLデッキにしてください。
**中身の文章・数字・順番は変えない。** 見せ方（図・アイコン・アニメーション・レイアウト）だけを設計する。

---

## 1. 基本の仕様

| 項目 | 内容 |
|---|---|
| 使い方 | Zoomで画面共有して投影（約60分＋質疑）。講師はクリックで進める |
| キャンバス | **1920×1080 の固定**。ブラウザの大きさに合わせて拡大・縮小する |
| ファイル | 編集用：`chNN_名前.html`＋共通の `assets/deck.css`・`assets/deck.js`。配布用：CSS・JS・画像を埋め込んだ**1ファイルのHTML**（画像はdata URI） |
| 外部読み込み | Googleフォント（Zen Kaku Gothic New・Dela Gothic One）のみ |
| 1スライド | `<section class="slide" data-min="分">` 1つ ＝ 1枚 |

## 2. 色（テイスト）

- **地はすべて淡い色**。黒や濃い色の背景は使わない。
  - 地 `#f3f5f8`（右上に白いぼかし）／カード `#ffffff`／淡いグレー `#eef1f5`
  - 文字 `#1d2128`、補足の文字 `#4f5661`、線 `#d9dee5`
- **章ごとのアクセント色を1つ**（見出しの小見出し・番号・強調・進捗バーに使う）

| 章 | アクセント | 濃い | 淡い |
|---|---|---|---|
| 第1章 防災 | `#e2600f`（炎） | `#b44a0a` | `#fde8d9` |
| 第2章 衛生・安全 | `#22915c`（緑） | `#17744a` | `#ddf2e7` |
| 第3章 労務／3-2章 ハラスメント | `#6b5ce7`（紫） | `#5243c9` | `#e9e6fd` |
| 第4章 経理 | `#c98a00`（金） | `#8f6200` | `#fbf0d3` |
| 第5章 法務／5-2章 メニュー | `#2f74d9`（青） | `#1f5bb5` | `#e0ebfb` |
| 第6章 情報管理 | `#d6406a`（ローズ） | `#b0284f` | `#fbe2ea` |
| キックオフ（全体） | `#138a86`（青緑） | `#0d6965` | `#daf1ef` |

- **意味の色は全章共通**
  - 赤 `#c23a2e`（淡 `#f9e3e0`）＝危険・禁止・罰則・やってはいけないこと
  - 緑 `#22915c`（淡 `#ddf2e7`）＝OK・やること・守られた状態・正解
  - 青 `#2f74d9`（淡 `#e0ebfb`）＝補足・情報
- 1枚の中で使う色は、アクセント＋意味の色まで。装飾のための色は足さない。

## 3. 文字

- 本文：**Zen Kaku Gothic New**（普通のゴシック）。数字だけ **Dela Gothic One**（太い数字）。
- 大きさの目安（1920幅）：注釈 24px／本文 32px／リード 42px／見出し 64px／大きな一文 92px／表紙 168px。
  **24px より小さい文字は使わない**（出典などの注記のみ 18px まで可）。
- 強調は太字（900）とアクセント色。下線・斜体は使わない。

## 4. ヘッダー（各スライドの上）

```
── 小見出し（アクセント色・字間広め・前に短い横線）
見出し（64px・太字・15字前後・1〜2行）
```
- 小見出し（`.eyebrow`）＝どの段階か（例：「自社の実例」「プラン（計画）」「それでも起きたら：初動対応」）
- 見出し（`.title`）＝このスライドで言いたいことを1文で
- プラン・キープ・アクトの章は、見出しの上に **P─K─A の進行マーク**（今の段階を塗る）
- プチテストなど、性質を示すラベルは**右上の小さな丸いラベル**

## 5. フッター（各スライドの下・自動で出る）

- 左：章名（例「第4章　経理管理」）／中央：**BALNIBARBI のロゴ**／右：クリックの進み具合（ドット）とページ番号「n / 全体」
- 一番下に、アクセント色の進捗バー
- 表紙・質疑応答・開始前の案内・外部資料の投影ページは `data-no-footer`（ロゴだけ）

## 6. 章の流れ（スライドの型）

開始前のお願い（必要なとき）→ タイトル → まず、お答えください（冒頭の投票）→ 事例 → なぜ起きるのか → 何を失うか → プラン・キープ・アクト（それぞれの前後にクイズ）→ それでも起きたら：初動対応・事後対応 → 研修修了レポート → 最後に（クロージング）→ 質疑応答

| スライド | ルール |
|---|---|
| **開始前のお願い** | 「お疲れ様です！！」＋開始時刻を大きく。カメラ**オン**（緑）・マイク**オフ**（赤）・表示名・スマートフォン・出席確認（赤枠）をカードで。目立たせたい語はバッジやマーカー＋ゆっくりした動き |
| **タイトル** | 「第○章」＋章名＋サブタイトル。右に章のテーマを表すイラスト。**「オンライン研修」「60分」は入れない** |
| **まず、お答えください** | 質問と回答のしかたを**1枚に**。回答はZoomの投票。台本の「◯％」「◯件」は口頭で読む |
| **事例** | 実際の画面・出来事を再現（LINE画面、時系列の流れなど）。数字はグラフや大きな数字で |
| **何を失うか** | **「会社」と「あなた個人」**に分ける。個人は**刑事・民事のラベル**。罰則は**「拘禁刑」**（懲役・禁錮は使わない）。条件つきの数字は文字でも残す |
| **プラン／キープ／アクト** | 箇条書きにしない。カード・アイコン・図で。**やること＝緑、やってはいけないこと＝赤** |
| **クイズ** | 「クイズ ①」＋「Zoomの投票で回答」。**1回目のクリックでカウントダウン開始**（選択式30秒・記述式1分）→ 0:00で赤の「時間です」→ **2回目のクリックで正解を表示**（正解は緑の枠と「正解」タグ、他は薄く）。1問2分。**正解率などの入力欄は作らない** |
| **初動対応** | **ステップの矢印**（記録 → すぐ本部へ → …）＋**STOP標識**（独断・隠蔽・報復など）。プチテスト形式のときは、空欄（薄いグレーの下線枠・幅は一律）→ 次のクリックで答え（赤・太字） |
| **事後対応** | ステップのフロー＋**「誰が」を示す役割のアイコン**（店長・シェフ → 担当役員 → 代表 → 総務 など） |
| **研修修了レポート** | 提出方法・期限（研修実施日から3日以内）・記入方法・**フォームのQRコードとURL**。レポートの項目はチップで簡潔に |
| **最後に** | キーメッセージを大きく。相談先 |
| **質疑応答** | 1枚。ロゴのみのフッター |
| **外部資料の投影** | 渡されたPDFのページは、**デザインを変えずに画像で全面表示**（白地・ロゴのみ） |

## 7. 1枚のルール

- **1枚で伝えることは1つ**。見出しは15字前後。
- **画面の文字は130〜380字が目安**（図の中の文字を含む）。事例・表は〜400字。800字を超えたら必ず減らす。
- **残す文**：定義・条件・数字・禁止事項・判断基準は、1〜2行の要点として画面にも出す（キーワードだけにしない）。
- **台本へ移す文**：読み上げるだけの長文・説明は画面から外し、台本に残す（**台本の文章は減らさない**）。
- 箇条書き・手順・役割は、**図・アイコン・カード**にする（フロー、役割アイコン、STOP標識、対比、時間軸、グラフ、メーター、人のピクトグラム）。
- **数字は図でも見せる**（大きな数字の数え上げ、棒グラフ、ドーナツ、人数アイコン）。
- アイコン・図は**1枚に10個前後まで**。人物は**人の形のピクトグラム**。
- 怖がらせる絵・過激な表現は使わない（けがの事例でも「安全なやり方」を絵にする）。
- 文字がはみ出す・重なる・フッターにかかることがないように（余白は上104px・左右128px・下150px）。逆に余白が大きく空きすぎるときは、文字とアイコンを大きくして埋める。

## 8. 動き（アニメーション）

- **クリックで1つずつ出す**のが基本。台本の［クリック］と画面の動きを**1対1**で対応させる。
- 動きは意味のあるものだけ（順序・因果・対比・変化・強調）。
- 画面のどこかに**ゆっくり動き続ける要素**を入れる（揺れる吹き出し、流れる矢印、点滅する警告、脈打つバッジ、上下するアイコン）。
- 動きを減らす設定（prefers-reduced-motion）では止める。

| やりたいこと | 書き方 |
|---|---|
| n回目のクリックで出す | `data-step="n"` |
| スライドに入ったら順にふわっと出す | `data-in` ＋ `style="--d:n"` |
| 場面を切り替える | `div.phase` ＋ `data-until="n"`（n回目より後で消える） |
| 数字を数え上げる | `data-count="66"` |
| 時間を数え下げる | `data-countdown="30"` ＋ `data-fmt="mmss"` |
| 予定時間 | `section` に `data-min="分"` |
| フッターをロゴだけに | `section` に `data-no-footer` |

## 9. 台本（notes）の出し方

- 各スライドの `<aside class="notes">` に、**MDの台本をそのまま**入れる（言い換えない・減らさない）。
- **［クリック］の数 ＝ そのスライドの `data-step` の最大値**（必ずそろえる）。［クリック］の前までが、そのクリックの前に話す内容。
- 進行役への指示は「（進行役：…）」。チャットに貼る文・URLは台本にそのまま書く。
- MDにクリックの印がない場合は、画面の動きに合わせて段落の頭に［クリック］を入れる。
- MDにない文を足したとき・画面から外したときは、**どこを変えたかを報告**する。
- 操作：→／スペース／クリック＝次へ、←＝戻る、**N＝台本を画面下に表示**、**P＝発表者ウィンドウ（台本・経過時間・予定時間・次のスライド）**、F＝全画面、画面下にマウス＝スライド一覧。

## 10. 用語・表記

| 使わない | 使う |
|---|---|
| 懲役・禁錮 | 拘禁刑 |
| 拒絶コスト | 拒絶リスク |
| ハラスメント防止（3-2章の章名） | ハラスメントからアジャストメントへ |
| 衛生管理（第2章の章名） | 衛生・安全管理 |

- 連絡先：ハラスメント相談窓口 **soudan@garb.co.jp**／保険の社内窓口 **insurance@garb.co.jp**（担当者名は出さない）

## 11. 修正のルール

- 内容の正は**MD**。デッキとMDが食い違ったらMDに合わせる。
- **指示されたスライドだけを直す**。それ以外を直したときは報告する。
- 指示がない限り、**クリック数・［クリック］・data-min は変えない**。
- **テイスト（今の見た目と部品）は変えない**。全面的な作り直しはしない。

## 12. 仕上げの確認

1. スライドごとの画面の文字数（台本を除く）が目安内か
2. 全スライドで ［クリック］の数 ＝ data-step の最大値
3. 直したスライドを、クリックを進めた状態で画像にして確認（はみ出し・重なり・小さすぎる文字・空きすぎる余白）
4. 台本がMDと一致しているか
5. 予定時間（data-min）の合計がMDの時間と合っているか
6. 配布用の1ファイルHTMLを作り、画像・QRが埋め込まれているか確認
